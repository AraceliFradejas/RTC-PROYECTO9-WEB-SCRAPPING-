# Guía de evidencias

En esta carpeta guardaré las capturas reales del proyecto. No modificaré las respuestas, los contadores ni el contenido de la terminal antes de capturarlos.

## Capturas previstas

| Archivo | Qué debe mostrar |
| --- | --- |
| `01-books-to-scrape-inicio.png` | La primera página del catálogo y su paginación |
| `02-inspeccion-tarjeta.png` | Una tarjeta y los elementos utilizados por los selectores |
| `03-scraper-inicio.png` | El comando y las primeras páginas procesadas |
| `04-scraper-progreso.png` | Una parte intermedia del recorrido y el contador acumulado |
| `05-scraper-resultado.png` | 50 páginas, 1.000 productos y cierre de Chromium |
| `06-products-inicio.png` | Los primeros objetos del JSON y sus campos |
| `07-products-final.png` | El último objeto y el cierre correcto del array JSON |
| `08-pruebas.png` | El resultado completo de `npm test` con 4 pruebas superadas |

## Criterios para las capturas

- Utilizaré nombres de archivo en minúsculas, sin espacios ni tildes.
- Mostraré el comando ejecutado y su resultado completo cuando sea posible.
- Evitaré que aparezcan credenciales, pestañas personales o información privada.
- No recortaré una captura de forma que desaparezca el contexto necesario.
- Actualizaré la memoria de `Pendiente` a `Completada` cuando exista cada archivo.
- Añadiré un texto alternativo descriptivo al insertar cada imagen.

MongoDB Atlas e Insomnia no forman parte de las evidencias actuales porque este proyecto no incorpora una base de datos ni un CRUD.
